FFVII Job System 0.8.0 (0.80 in 7th Heaven) - Willard82

Replaces the native DLL loading path with 7th Heaven HEXT patches and a
freestanding runtime. No LoadLibrary, plugin, assembly or external-program
declarations are present, avoiding the native-library activation prompt
without changing 7th Heaven's security settings.

Retains all 25 shared class choices, existing defaults and saved selections,
Materia permissions, weapon icons, original accessory rules, class/accessory
guides, preview artwork and support links.

Private native and installed-7H integration checks pass. This new loading
backend awaits an in-game test by the author before public release.
