Adds FFVII Job System 1.0.0 by Willard82 for the original English Steam edition of FFVII. Each of the nine characters can choose any of 25 Final Fantasy classes before launch. Materia permissions and character weapon icons follow the selected classes. Configure Mod includes class descriptions, Materia lists and an accessory reference; class-based accessory suggestions are informational.

The mod uses HEXT patches and a freestanding runtime. It contains no DLL/plugin/program load declarations. Source for the runtime and build is public in the project repository.
